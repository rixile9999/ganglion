Module 1. Learning Phase (Reflex-LM 학습)

[ 04 / 08 ]
Spec-Driven Data Synthesis (명세 기반 데이터 합성) 주어진 스키마 명세([ToolSpec](file:///Users/janghyoseog/workspace/reflex-language-model/ganglion/contract/tool_spec.py))를 파싱하여, 학습용 시나리오 질의와 이에 매칭되는 정답 Action IR 문자열을 템플릿 기반으로 자동 매핑·합성.
Supervised Fine-Tuning (SFT) 경량 에이전트 전용 초소형 파라미터 모델(0.6B) 학습. 툴당 약 80~100건 수준의 학습 세트만으로도 Action IR에 최적화된 토큰 예측 및 고유 구조 포맷 학습 가능.
Direct Preference Optimization (DPO) 연동 지원 단일 툴 지정을 넘어, 다수 툴 간의 혼동이나 애매모호한 문맥(Irrelevance 등)을 제어하기 위해 Preference Alignment 튜닝 레이어 통합.

Module 2. Compiler Passes (Myelin Compiler)

[ 05 / 08 ]

1. Constrained Decoding (Grammar)

EBNF 구문 강제 Masking [Catalog](file:///Users/janghyoseog/workspace/reflex-language-model/ganglion/contract/catalog.py) 정보로부터 BNF/EBNF 제약 규칙을 동적 빌드.
출력 안정성 100% 보장 추론 시점에 유효하지 않은 JSON/DSL 토큰 후보군을 엔진단에서 마스킹 차단하여 포맷 붕괴 원천 차단.

2. Dynamic Post-Correction

Default Value Injection 모델이 누락한 필수 인자를 컴파일 파서 레벨에서 사전 디폴트값 보완 후 툴 실행.
샌드박스 Repair Loop 실행 에러 감지 시 격리된 환경 내에서 오류 로그 피드백을 프롬프트로 재전송하는 [Repair Loop](file:///Users/janghyoseog/workspace/reflex-language-model/ganglion/analyzer/repair.py) 구동.
